# LOGIN

MiniClaw Swarm: several Codex and Claude agents work towards one shared goal, and the swarm keeps
going when an agent's link breaks. It is built on MiniClaw (Linux build; the original README is
`UPSTREAM-README.md`).

- **Set up a new computer (Linux, Windows with WSL, macOS): [SETUP.md](SETUP.md).**
- Run: `npm ci`, then `npm start`, and open http://127.0.0.1:8787 → **Swarm** in the sidebar.
- How it works, and the API for the status page and the issue board: [docs/swarm](docs/swarm/README.md).
